# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, discrimination and
personal attacks are not tolerated in issues, pull requests, discussions or any
other project space.

## Enforcement

Instances of unacceptable behavior can be reported privately to the maintainer
through GitHub (use a private security advisory or contact the repository owner,
[@Cedsson](https://github.com/Cedsson)). All reports are reviewed and handled
confidentially. The maintainer may remove comments, close discussions, or block
participants who violate this code.
